> 💡 თუ გინდა რომ ყველაფერი 100%-ით გამართულად მუშაობდეს ლოკალურადაც, ჯობს მცირე

## 🔐 ადმინ-პანელი (რედაქტირება)

1. საიტზე ქვედა-მარჯვენა კუთხეში არის ⚙️ ღილაკი — დააჭირე.
2. შეიყვანე პაროლი. **საწყისი პაროლია: `saba2026`**
   → შესაცვლელად გახსენი `assets/js/data.js`, იპოვე `adminPassword` და ჩაწერე შენი.
3. ჩაირთვება **EDIT MODE**. ახლა შეგიძლია:

| მოქმედება | როგორ |
|---|---|
| **ტექსტის შეცვლა** | დააჭირე ნებისმიერ ტექსტს (სათაური, ბიო, განცხადება…) და დაწერე |
| **ნამუშევრის გადაადგილება** | დაიჭირე ბარათი და გადაათრიე სხვა ბარათზე — ადგილებს გაცვლიან |
| **ზომის შეცვლა** | ბარათზე ⤢ → აირჩიე sm / md / lg / wide / tall |
| **ნამუშევრის რედაქტირება** | ბარათზე ✎ → შეცვალე სათაური/წელი/მასალა/აღწერა ან თვით სურათი |
| **წაშლა** | ბარათზე ✕ |
| **ახალი ნამუშევარი** | ზედა ზოლში „+ ნამუშევარი" |
| **გამოფენების/ჯილდოების ჩამატება** | სექცია Exhibitions → „+ ჩანაწერის დამატება" (ან დააჭირე სტრიქონს) |
| **Journal პოსტი** | სექცია Journal → „+ პოსტის დამატება" |
| **დეტალურ გვერდზე ფოტო/ვიდეო** | გახსენი ნამუშევარი → „+ ფოტოს ატვირთვა" / „+ ვიდეოს დამატება" |

გასასვლელად — ზედა ზოლში **Exit**.

## 💾 როგორ ინახება ცვლილებები (მნიშვნელოვანია)

რადგან საიტი სტატიკურია (სერვერის გარეშე, GitHub Pages-ზე მუშაობს), ცვლილებები
ინახება **შენს ბრაუზერში** (localStorage). ანუ შენ ხედავ ცვლილებებს, მაგრამ სხვა
ვიზიტორი ჯერ ისევ საწყის ვერსიას ხედავს.

რომ ცვლილებები **ყველამ** დაინახოს:

1. ადმინ-რეჟიმში ზედა ზოლში დააჭირე **⬇ Export JSON** — გადმოიწერება `deliquente-data.json`.
2. ეს ფაილი არის შენი საიტის ახალი შიგთავსი. ორი გზაა:
   - **მარტივი:** გადმოწერილ ფაილს გადაარქვი და ჩასვი ფოლდერში, შემდეგ ადმინ-რეჟიმში
     **⬆ Import** ღილაკით ჩატვირთე — ასე გადაიტან ცვლილებებს სხვა კომპიუტერზე.
   - **სამუდამოდ ყველასთვის:** გახსენი `deliquente-data.json`, დააკოპირე შიგთავსი და
     ჩაანაცვლე `assets/js/data.js`-ში `DEFAULT_DATA = { … }`-ის მნიშვნელობა. შემდეგ
     ატვირთე GitHub-ზე — ეს გახდება ახალი „ქარხნული" ვერსია.

> შემდეგ ეტაპზე შემიძლია დავამატო ნამდვილი ბექენდი (მაგ. პატარა მონაცემთა ბაზა),
> რომ ცვლილებები ავტომატურად შეინახოს ღილაკის დაჭერისთანავე — უბრალოდ მითხარი.

## 🌍 GitHub-ზე ატვირთვა და გამოქვეყნება (GitHub Pages)

ვებგვერდიდან (ბრაუზერით, ტერმინალის გარეშე):

1. გადი [github.com](https://github.com) → **New repository**.
   სახელი: `deliquentepensamiento-web` (პატარა ასოებით, ჰიფენით).
2. **Add file → Upload files** → ჩააგდე ამ ფოლდერის **შიგთავსი** (index.html, assets, images…).
   > ⚠️ ატვირთე ფაილები, თვითონ ფოლდერი არა — ანუ `index.html` უნდა იყოს repo-ს ფესვში.
3. Commit.
4. **Settings → Pages → Build and deployment → Source: „Deploy from a branch"**,
   Branch: `main` / `(root)` → **Save**.
5. 1–2 წუთში საიტი გამოჩნდება მისამართზე:
   `https://<შენი-იუზერი>.github.io/deliquentepensamiento-web/`

ან ტერმინალით (Git-ით):
```bash
cd "Deliquentepensamiento - Web"
git init
git add .
git commit -m "Initial site"
git branch -M main
git remote add origin https://github.com/<USER>/deliquentepensamiento-web.git
git push -u origin main
```
